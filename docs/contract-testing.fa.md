# بررسی قرارداد و مرز سورس

[English](contract-testing.md) · [فارسی](contract-testing.fa.md)

`npm run test:coverage` آزمون‌های منتشرشدهٔ HTTP، collection، معماری و
اعتبارسنجی ورودی را همراه آزمون‌های برنامه، ذخیره‌سازی و دیگر آزمون‌ها اجرا
می‌کند. `npm run check:boundaries` مرزهای سورس و import قرارداد را بررسی می‌کند.
آزمون‌های مرز، محافظ‌های static، type-only، dynamic، re-export، require و
alias حل‌شده را می‌سنجند. [فهرست اعتبارسنجی](../.agents/validation.json) مرجع
بررسی کامل است: پیش از commit یا تحویل PR مجاز، `npm run validate -- full`
را اجرا کنید. آزمون مصنوعی مجوز را در سرویس مستقرشده ثابت نمی‌کند.

آزمون قرارداد مصرف‌کننده متعلق به کلاینت‌های مستقلاً منتشرشونده است. تأیید
خودکار provider Pact در این پروژه پیاده نشده و ادعا نمی‌شود. قراردادهای مستقل عمداً snapshot هستند؛
تعهد انتشار سازگاری فیلد، وضعیت، احراز هویت و کوکی عمومی است، نه یکسان بودن
سورس بسته‌ها.
