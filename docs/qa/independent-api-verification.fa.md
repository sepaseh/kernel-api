# بررسی API مستقل — ۲۰۲۶-۱۰-۲۴

[English](independent-api-verification.md) · [فارسی](independent-api-verification.fa.md)

این پرونده گزارشی تاریخی دربارهٔ ۲۴ اکتبر ۲۰۲۶ است؛ ادعاهای اجرای آن مستقلاً تأیید نشده‌اند و وضعیت کنونی پروژه را نشان نمی‌دهند. برای بررسی‌های جاری، [اعتبارسنجی](../validation.fa.md) را ببینید.

این تصویر اجرای پیش از ممیزی مجدد نیازمندی‌ها و سناریوهای بازیابی/رخداد جدید
است. شمارها به همان اجرای تاریخ‌دار تعلق دارند؛ برای افزوده‌ها و محدودهٔ فعلی
[ممیزی نیازمندی‌ها](requirements-audit-2026-10-24.fa.md) را ببینید.

بررسی‌ها در kernel-api روی ویندوز با Node.js 24.18.0 و npm 12.0.2 اجرا شدند.
checkout اصلی، فایل محیط واقعی و دادهٔ موجود اجرا ورودی تست نبودند. commit، push
یا استقرار راه‌دور انجام نشد.

`npm run validate -- full` هر ۱۵ بررسی الزامی را با موفقیت اجرا کرد: ۱۰۹ تست
API، ۱۶ تست قرارداد HTTP منتخب، ۲۴ تست استقرار، ۱۸ تست ابزار، ۹ تست یکپارچگی
کاتالوگ، ۱۴ تست راهنمای دستیار، ۶ تست مرز workspace و ۴ مورد معماری لایهٔ
کاربرد/ارائه. بعضی مجموعه‌ها هم‌پوشانی دارند؛ عددها متعلق به هر دستور هستند و
جمع تست‌های یکتا نیستند. بررسی نوع، lint، قالب‌بندی، Knip و build مربوط به
TypeScript مستقیم موفق بودند. audit آنلاین بدون مورد high/critical و با چهار
مورد moderate در زنجیرهٔ MinIO تکمیل شد: decode-uri-component، query-string،
stream-json و minio. آستانهٔ موجود `--audit-level=high` است و وابستگی‌ها برای
پنهان‌کردن یا خاموش‌کردن این یافته‌ها تغییر نکردند.

`npm run test:deploy:native` روی انتشار تغییرناپذیر تازه‌بسته‌بندی‌شده موفق بود:
نصب وابستگی صرفاً اجرایی، پیش‌بررسی محیط، مهاجرت، ساخت مدیر اولیه، health و HTTP
احرازشده از خود بسته اجرا شدند. دادهٔ ساختگی در پوشهٔ موقت جدا بود و بسته و
داده پس از بررسی حذف شدند. این نتیجه بستهٔ ویندوز را تأیید می‌کند؛ اجرای
systemd در Linux، مجوز میزبان، DNS و Certbot بررسی عملی نشدند.

`npm run test:deploy:docker` روی موتور Linux محلی موفق بود. تصویر مستقل API و
Nginx ساخته شد و آمادگی HTTPS، رد میزبان HTTP و نام TLS ناشناخته، تغییرمسیر
HTTP، شناسهٔ تغییرناپذیر انتشار و no-store، bootstrap یک‌بارهٔ مدیر، cookie امن
و نشست احرازشده، رد Origin بیگانه، خطای صریح نبود ارسال واقعی OTP، جداسازی فایل
عمومی/خصوصی و باقی‌ماندن فایل و نشست پس از جایگزینی container API بررسی شدند.
اعتبارنامه و گواهی ساختگی، پروژهٔ Compose، volume، شبکه و فایل موقت متعلق به
تست حذف شدند. Docker context راه‌دور استفاده نشد.

تست‌های استقرار، جلوگیری از خروج پیوند پوشهٔ منبع در سطح ریشه و درون درخت،
محدودماندن خروجی تغییرناپذیر و رد مسیر دادهٔ پایدار منتهی به داخل انتشار از راه
پیوند پوشه را نیز پوشش می‌دهند. shell اعتبارسنجی gateway برای اجرای Linux از
LF استفاده می‌کند. پس از آخرین ویرایش اسناد، راهنمای فعال و قالب‌بندی دوباره
بررسی شدند.

این نتیجه ادعای اجرای CI/CodeQL/Sonar/DAST میزبانی‌شده، provider واقعی OTP،
عملیات MinIO خارجی، backup زمان‌بندی‌شده، تمرین بازیابی تولید یا benchmark تازهٔ
درک دستیار نیست.
