# وضعیت ۱۳۷ موضوع برای API

[English](roadmap-status-2026-10-24.md) · [فارسی](roadmap-status-2026-10-24.fa.md)

این پرونده گزارشی تاریخی دربارهٔ ۲۴ اکتبر ۲۰۲۶ است؛ ادعاهای اجرای آن مستقلاً تأیید نشده‌اند و وضعیت کنونی پروژه را نشان نمی‌دهند. برای بررسی‌های جاری، [اعتبارسنجی](../validation.fa.md) را ببینید.

Date: 2026-10-24.

این جدول عنوان هر ۱۳۷ موضوع و وضعیت API را حفظ می‌کند و مالکیت، پایهٔ پیاده‌شده، گردش‌کار، شرط و کار بهره‌بردار را مشخص می‌کند. هر موضوع نیازمندی خودکار محصول یا الزام نصب فناوری نیست. این طبقه‌بندی اجرای تازهٔ آزمون را ثبت نمی‌کند.

[جدول ماشینی](roadmap-status-2026-10-24.json) فقط مسیر شاهد API نسبت به همین مخزن را دارد. برای رفتار و محدودهٔ اجرای واقعی، [ممیزی نیازمندی](requirements-audit-2026-10-24.fa.md)، [نقشهٔ کار](../source-navigation.fa.md) و گزارش تاریخ‌دار بررسی را بخوانید.
