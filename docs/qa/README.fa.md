# گزارش بررسی API

[English](README.md) · [فارسی](README.fa.md)

این پرونده گزارشی تاریخی دربارهٔ ۲۴ اکتبر ۲۰۲۶ است؛ ادعاهای اجرای آن مستقلاً تأیید نشده‌اند و وضعیت کنونی پروژه را نشان نمی‌دهند. برای بررسی‌های جاری، [اعتبارسنجی](../validation.fa.md) را ببینید.

نتیجه را از اجرای واقعی با تاریخ، محدودهٔ سورس و محدودیت محیط ثبت کنید. آزمون از
fixture مصنوعی و موقتی استفاده می‌کند. تأیید payload native در ویندوز، اجرای
systemd/مجوز Linux یا Certbot را ثابت نمی‌کند. smoke Docker اجرای واقعی موتور
Linux محلی می‌خواهد. بررسی محلی ادعای CI/CodeQL/Sonar/DAST/staging/production
میزبانی‌شده یا benchmark دستیار ایجاد نمی‌کند.

- [بررسی محلی API — ۲۰۲۶-۱۰-۲۴](independent-api-verification.fa.md) نتیجهٔ پروفایل
  کامل، payload native و smoke HTTPS در Docker را ثبت می‌کند.
- [ممیزی نیازمندی API — ۲۰۲۶-۱۰-۲۴](requirements-audit-2026-10-24.fa.md) رفتار
  پیاده‌شده، کار عملیاتی بیرونی و تصمیم وابسته به provider را تفکیک می‌کند.
- [گزارش اجرای API — ۲۰۲۶-۱۰-۲۴](standalone-layout-2026-10-24.fa.md) اجرای بعدی
  دروازهٔ کامل، بستهٔ تولید و پاک‌سازی محدود Docker را ثبت می‌کند.
- [وضعیت ۱۳۷ موضوع API](roadmap-status-2026-10-24.fa.md) مالکیت، شرط و شاهد API
  را ثبت می‌کند و هر موضوع را نیازمندی خودکار محصول نمی‌داند.
- [مشاهدات فهم سورس API — ۲۰۲۶-۱۰-۲۴](source-comprehension-2026-10-24.fa.md)
  پنج مشاهدهٔ تاریخ‌دار و محدودیت کشف دستی دستور را حفظ می‌کند؛ ارزیابی تازه یا
  نتیجهٔ بارگذاری خودکار میزبان نیست.
