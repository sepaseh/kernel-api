# مشاهدات فهم سورس API — ۲۰۲۶-۱۰-۲۴

[English](source-comprehension-2026-10-24.md) · [فارسی](source-comprehension-2026-10-24.fa.md)

این پرونده گزارشی تاریخی دربارهٔ ۲۴ اکتبر ۲۰۲۶ است؛ ادعاهای اجرای آن مستقلاً تأیید نشده‌اند و وضعیت کنونی پروژه را نشان نمی‌دهند. برای بررسی‌های جاری، [اعتبارسنجی](../validation.fa.md) را ببینید.

رکورد تاریخ‌دار پنج مشاهدهٔ API دارد: سه سناریوی کامل و دو سناریوی با پوشش جزئی معیار. این صفحه خلاصهٔ همان رکوردهای موجود است؛ ارزیابی تازه یا تغییر پاسخ ثبت‌شده نیست. پوشش جزئی شامل نکته‌هایی است که سؤال اولیه صریح نپرسیده بود و دو نقص اجرایی را ثابت نمی‌کند.

کشف دستورها دستی و از پوشهٔ داده‌شده بود؛ بارگذاری خودکار میزبان سنجیده نشد. دستیار اعلام کرد آزمون، برنامه، شبکه، نصب یا ویرایش سورس انجام نداده؛ رد کامل ابزار مستقلاً ثبت و بررسی نشده است. model/version، توکن، هزینه و زمان پاسخ نامعلوم می‌مانند. این مشاهدات دقت عمومی مدل، عملکرد اجرایی، کیفیت زبانی یا آمادگی استقرار را ثابت نمی‌کنند.

## شاهد ورودی حفظ‌شده

ورودی در ۲۰۲۶-۱۰-۲۴ ثبت شده و اثر انگشت آن این است:

`1405d707da7c48c2c7036e08432270db6433529d17b926952588eea4b32e5690`

[رکورد ماشینی](../../.agents/evaluation/runs/2026-10-24-source-audit.json) هر پنج مشاهدهٔ API، سؤال ارائه‌شده، معیار، revision ورودی، هش سورس و خواندن اعلام‌شدهٔ دستور را دقیقاً حفظ می‌کند. مسیر و هش snapshot شناسهٔ همان ورودی تاریخ‌دار است، نه نقشهٔ فعلی یا اثر انگشت درخت کاری فعلی.

ورودی پیش از اصلاح هدر زبان API بود. دستیار مقدار خام و پشتیبانی‌نشدهٔ Content-Language همراه با fallback اضطراری انگلیسی را توصیف کرد. regression و اصلاح جداگانهٔ بعدی، حل زبان هدر و مترجم را بدون بازنویسی تنظیم ذخیره‌شده یا تغییر رد DTO عمومی هماهنگ کرد. این مشاهده متعلق به ورودی ارزیابی است و نقص حل‌نشدهٔ فعلی نیست.

## مشاهدات ثبت‌شدهٔ API

| سناریو                    | نتیجه | مشاهده و محدودیت                                                                                                                                                                                           |
| ------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| session-lifecycle         | کامل  | نشست opaque بدون چرخش، کوکی بومی و ابطال تراکنشی همهٔ نشست‌ها با شاهد سورس توضیح داده شد.                                                                                                                  |
| persisted-language        | کامل  | مرجع تنظیم ذخیره‌شده، پیش‌فرض انگلیسی و حفظ مقدار موجود، نادیده‌گرفتن ترجیح بازدیدکننده و DTO عمومی no-store پوشش داده شد. ناسازگاری قدیمی هدر/fallback پس از snapshot اصلاح شد.                           |
| shared-label              | جزئی  | هویت محلی پیام، ده کاتالوگ، نحو {{variable}}، مرز موتور و import حذف‌شونده پوشش داده شد. تفکیک کامل نحو interpolation مصرف‌کننده‌ها صریح نبود و سؤال هم هر دو نحو را صریح نپرسیده بود.                     |
| administrator-concurrency | کامل  | transport نازک، سیاست مستقل از فریم‌ورک و خواندن/شمارش دوباره داخل تراکنش واقعی درست تفکیک شد.                                                                                                             |
| private-media             | جزئی  | مجوز، URL و خواندن خصوصی، جبران شکست، حد پس از parse در برابر ingress و حفاظت دادهٔ مالک پوشش داده شد. نقطهٔ بازیابی هماهنگ و دامنهٔ drill در معیار بود ولی سؤال آن را صریح نپرسیده و پاسخ پوشش نداده بود. |

صورت سؤال بعدی دربارهٔ تفاوت interpolation و بازیابی هماهنگ/drill روشن‌تر شد؛ با همان دستیار دوباره اجرا یا امتیازدهی نشد و بهبود عددی ادعا نمی‌شود. [روش فعلی ارزیابی](../comprehension-evaluation.fa.md) و [ممیزی نیازمندی](requirements-audit-2026-10-24.fa.md) مرجع راهنما و رفتار جاری‌اند.
