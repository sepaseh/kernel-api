# Runtime sequences

[English](sequences.md) · [فارسی](sequences.fa.md)

ورود از parse و بررسی Origin در HTTP به سیاست برنامه، درگاه Better Auth،
ثبت اعتبارنامه/نشست و بازگرداندن کوکی رسمی و DTO توکن می‌رود. مصرف‌کننده می‌تواند از bearer یا پراکسی هم‌مبدأ با کوکی HttpOnly استفاده کند؛
این آداپتورها متعلق به کلاینت‌های مستقل هستند. refresh همان توکن نشست
opaque را برمی‌گرداند؛ JWT rotation یا تشخیص reuse پیاده نشده است. خروج idempotent
است و نام واقعی کوکی امن provider را منقضی می‌کند. تغییر یا بازیابی رمز همراه
با تغییر اعتبارنامه همهٔ نشست‌های قدیمی را باطل می‌کند.

تغییر مدیریتی پس از احراز و مجوز به سرویس ویژگی می‌رود. عملیاتی که می‌توانند
آخرین مدیر را تحت تأثیر قرار دهند، وضعیت او را در تراکنش نوشتن دوباره می‌خوانند؛
query پیشین یا پنهان‌کردن دکمه تضمین نیست.
آپلود سیاست عمومی/خصوصی را بررسی، بایت را ذخیره و metadata را ثبت می‌کند و
در شکست metadata حذف جبرانی انجام می‌دهد. metadata خصوصی URL عمومی ندارد و
endpoint دانلود خصوصی HTTP پیاده نشده است.

API ابتدا شنوندهٔ HTTP را متصل می‌کند و تا پایان آماده‌سازی پاسخ ۵۰۳ غیرقابل
ذخیره در cache می‌دهد. سپس پایگاه داده را با مهاجرت و حفظ تنظیمات آماده می‌کند،
ذخیره‌سازی را آماده می‌کند و برنامهٔ ترکیب‌شده را ارائه می‌دهد؛ توقف منابع را
با زمان محدود می‌بندد.
[معماری](architecture.fa.md) مالکیت سرویس و adapter را توضیح می‌دهد.
