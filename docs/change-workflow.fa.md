# برنامه‌ریزی تغییر API

[English](change-workflow.md) · [فارسی](change-workflow.fa.md)

رفتار درخواستی، مخزن مسئول، مصرف‌کنندگان و سناریوهای پذیرش قابل مشاهده را ثبت
کنید. با [مسیر‌یابی](source-navigation.fa.md)، قرارداد، سرویس، آداپتور و
آزمون‌های مرتبط را بخوانید. تغییرات محلی موجود را حفظ و اعتبارنامه و دادهٔ
خصوصی را از داده‌های آزمون کنار بگذارید.

ورودی نامعتبر، مجوز، سازگاری داده و قرارداد را در صورت ارتباط توضیح دهید.
پیش از پیاده‌سازی وابستگی مهاجرت یا انتشار را مشخص، سپس بررسی‌های متمرکز و
[اعتبارسنجی کامل](validation.fa.md) را پیش از تحویل مجاز اجرا کنید. اجرای
انجام‌نشده یا تأیید راه دور دریافت‌نشده را گزارش نکنید.
