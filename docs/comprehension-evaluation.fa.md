# موارد درک کد API

[English](comprehension-evaluation.md) · [فارسی](comprehension-evaluation.fa.md)

[تعریف موارد](../.agents/evaluation/cases.json) سه کار فقط‌خواندنی را شرح می‌دهد:
ردیابی احراز هویت و ابطال نشست، توضیح رفتار زبان ذخیره‌شده و تفکیک تمرین
بازیابی مصنوعی از شواهد استقرار. هر مورد شناسهٔ کار، منبع شواهد، توضیح مورد
انتظار، محدودیت و شناسهٔ بررسی‌ها را مشخص می‌کند. این تعریف‌ها راهنمای بازبینی
هستند و نتیجهٔ benchmark یا اثبات اجرای کار توسط یک دستیار نیستند.

فایل محیط خصوصی، دادهٔ موجود کاربران یا وضعیت تولید را نخوانید. از
[نقشهٔ کارها](../.agents/navigation.json) و
[فهرست اعتبارسنجی](../.agents/validation.json) فعلی استفاده کنید؛ نتیجهٔ هر
بررسی فقط پس از اجرای واقعی آن قابل گزارش است. از این موارد نتیجه نگیرید که
ارسال OTP در تولید یا پشتیبان‌گیری اپراتور انجام شده است.
