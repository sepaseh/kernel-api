# Branch protection policy

[English](branch-protection.md) · [فارسی](branch-protection.fa.md)

از اتصال‌های موجود GitHub، CodeRabbit و SonarQube Cloud استفاده کنید. ادغام به
موفقیت CI، بررسی‌های اصلی الزامی سرویس‌ها، یک بازبینی تأییدشده و حل گفتگوها نیاز
دارد. این قانون برای مدیران هم برقرار است؛ تأیید قدیمی بی‌اعتبار، شاخهٔ به‌روز و
تاریخچهٔ خطی الزامی و force push و حذف شاخه ممنوع است.

در مرحلهٔ قواعد کار، بررسی‌های **Bootstrap governance (API not published)** و
**SonarQube Cloud analysis** از GitHub Actions و **SonarCloud Code Analysis** از
برنامهٔ SonarQube Cloud الزامی‌اند. وضعیت اصلی **CodeRabbit** هم الزامی است. شرایط CI هر مرحله
تنها پس از تأیید اجرای واقعی بررسی‌های جانشین عوض شوند؛ برای ادغام کار ناقص، یک
شرط الزامی را حذف نکنید.

وضعیت پیشرفت CodeRabbit ممکن است برای بازبینی انجام‌نشده موفق باشد. نتیجهٔ واقعی
بازبینی را بخوانید و یافته‌های عملی را رفع کنید؛ اگر بازبینی خودکار انجام نشد،
بازبینی دستی درخواست و سهمیه را رعایت کنید. تأیید خودکار تنظیم‌شدهٔ CodeRabbit
می‌تواند پس از تکمیل بازبینی، تأیید لازم را ثبت کند. شرط عمومی تأیید GitHub، سایر
بازبین‌های مجاز را هم می‌پذیرد؛ این سیاست معمول ادعای الزام هویت یک ربات خاص ندارد.

App تأیید اختصاصی، ناشر بیرونی یا بررسی سفارشی تأیید استفاده نمی‌شود. نتایج CI و
Sonar باید مربوط به کامیت فعلی PR باشند. بررسی الزامی مفقود یا ناموفق ادغام را
می‌بندد؛ برای دورزدن شکست، شرط را حذف نکنید. CODEOWNERS بازبین را پیشنهاد می‌کند و
به‌تنهایی حفاظت را تنظیم نمی‌کند.
