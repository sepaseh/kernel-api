# ADR 0005: مالکیت مخزن و قرارداد HTTP

[English](0005-independent-repositories.md) · [فارسی](0005-independent-repositories.fa.md)

وضعیت: پذیرفته‌شده. این API یک پروژهٔ قابل نصب npm با سورس در src/، مهاجرت‌های SQL
در drizzle/، پیکربندی ریشه و یک package.json/lockfile است. قراردادها و کاتالوگ کامل
زبان‌ها به‌صورت سورس محلی نگهداری می‌شوند.

فقط API مالک بکند، DB، مهاجرت، احراز هویت و ذخیره‌سازی است. مصرف‌کننده از origin
تنظیم‌شدهٔ HTTP استفاده می‌کند. یکسانی نوع به‌تنهایی سازگاری را ثابت نمی‌کند؛ فیلد،
status، کوکی نشست و زبان تنظیم‌شده را برای انتشار مرتبط بررسی کنید.

آزمون، راهنما، CI و دستور عملیاتی Docker و native متعلق به همین مخزن است. داده و
راز استقرار متعلق به بهره‌بردار است و بیرون کد انتشار تغییرناپذیر می‌ماند.
[معماری](../architecture.fa.md)، [استقرار](../deployment.fa.md) و
[ارزیابی](../comprehension-evaluation.fa.md) را ببینید.
