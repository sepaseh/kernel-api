# ADR 0003: یک زبان فعال ذخیره‌شده

[English](0003-single-active-language.md) · [فارسی](0003-single-active-language.fa.md)

وضعیت: پذیرفته‌شده. تنظیمات ذخیره‌شدهٔ API یک زبان را انتخاب می‌کند. تنظیم تازه
انگلیسی است و مقدار موجود حفظ می‌شود. هر ده کاتالوگ محلی این انتخاب را پشتیبانی
می‌کنند؛ هدر، کوکی، query و پیشوند زبان URL آن را عوض نمی‌کنند. فقط مدیر کل سیستم
می‌تواند این تنظیم ذخیره‌شده را تغییر دهد. ویرایشگر تنظیمات مجوز قالب/لوگو را با
ورودی اختیاری language_code حفظ می‌کند. ذخیرهٔ عادی همیشه ستون زبان را حذف می‌کند،
حتی با ورودی صریح برابر مقدار فعلی، تا تغییر هم‌زمان مدیر کل حفظ شود.

کد ذخیره‌شدهٔ پشتیبانی‌نشده بدون بازنویسی داده برای پیام و Content-Language به
انگلیسی حل می‌شود. GET /settings عمومی فرادادهٔ زبان نامعتبر را رد می‌کند و تغییر
تنظیمات توسط مدیر کل می‌تواند آن را ترمیم کند. مصرف‌کننده DTO عمومی را طبق نیاز خود اعتبارسنجی می‌کند.

[تنظیمات](../../src/application/settings.ts) و [ترجمه](../localization.fa.md) را ببینید.
