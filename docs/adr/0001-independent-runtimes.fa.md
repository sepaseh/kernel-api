# ADR 0001: مرز اجرای API

[English](0001-independent-runtimes.md) · [فارسی](0001-independent-runtimes.fa.md)

وضعیت: پذیرفته‌شده. API مالک احراز هویت، دسترسی DB، مهاجرت‌های SQL بازبینی‌شده و
ذخیره‌سازی است. مصرف‌کنندهٔ HTTP از origin صریح تنظیم‌شده و قرارداد سازگار درخواست و
پاسخ استفاده می‌کند. رندر رابط کاربری متعلق به اجرای API نیست.

این مخزن یک API با package و lockfile در ریشه می‌سازد. قراردادها و کاتالوگ‌ها ماژول
محلی سورس هستند. [مالکیت مخزن](0005-independent-repositories.fa.md) و
[معماری](../architecture.fa.md) را ببینید.
