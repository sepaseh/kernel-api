# ترجمهٔ API

[English](localization.md) · [فارسی](localization.fa.md)

API مالک ده کاتالوگ پیام محلی است. فرادادهٔ زبان‌ها در `src/contracts/locales.ts`
و واژگان کاربردی بدون وابستگی اجرایی در `src/application/localization.ts`
تعریف شده‌اند و آداپتور زیرساخت ترجمه را تعیین می‌کند. کلیدها و متغیرهای
درون‌یابی را در همهٔ زبان‌ها هماهنگ نگه دارید.

زبان ذخیره‌شدهٔ سیستم زبان پاسخ را تعیین می‌کند و ترجیح بازدیدکننده آن را
تغییر نمی‌دهد. پیش از تغییر، [انتقال HTTP](http-transport.fa.md)،
[معماری](architecture.fa.md) و آزمون‌های کاتالوگ و HTTP را ببینید. کاتالوگ‌های
رابط کاربری متعلق به برنامه‌های مستقل خودشان هستند.
