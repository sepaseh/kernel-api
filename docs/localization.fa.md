# ترجمهٔ API

[English](localization.md) · [فارسی](localization.fa.md)

API مالک ده کاتالوگ پیام محلی است. فرادادهٔ زبان‌ها در `src/contracts/locales.ts`
و واژگان کاربردی بدون وابستگی اجرایی در `src/application/localization.ts`
تعریف شده‌اند و آداپتور زیرساخت ترجمه را تعیین می‌کند. کلیدها و متغیرهای
درون‌یابی را در همهٔ زبان‌ها هماهنگ نگه دارید.

زبان ذخیره‌شدهٔ سیستم زبان پاسخ را تعیین می‌کند و ترجیح بازدیدکننده آن را
تغییر نمی‌دهد. پیش از تغییر، [انتقال HTTP](http-transport.fa.md)،
[معماری](architecture.fa.md) و آزمون‌های کاتالوگ و HTTP را ببینید. کاتالوگ‌های
رابط کاربری متعلق به برنامه‌های مستقل خودشان هستند.

## اختیار زبان سراسری سیستم

زبان فعال یک تنظیم سراسری سیستم است و ترجیح حساب کاربری نیست. فقط حساب دارای
is_system_admin=true می‌تواند آن را عوض کند. نقش دارای settings.update همچنان
مجوز ذخیرهٔ قالب و لوگو را دارد و اختیار مدیریت زبان نمی‌گیرد.

فیلد language_code در PUT /settings اختیاری است. فراخوان عادی باید آن را حذف کند.
کد صریح برابر مقدار فعلی برای سازگاری پذیرفته می‌شود، اما سرویس همیشه این فیلد را
از تغییر persistence آن حساب حذف می‌کند. بنابراین ذخیرهٔ ظاهر توسط کاربر عادی،
تغییر هم‌زمان زبان توسط مدیر کل را بازنویسی نمی‌کند. کد متفاوت پیش از هر نوشتن
تنظیم با خطای مجوز رد می‌شود. مدیر کل می‌تواند کد ثبت‌شده بفرستد یا برای حفظ مقدار
ذخیره‌شده فیلد را حذف کند. قواعد palette کامل و اعتبارسنجی لوگوی عمومی حفظ می‌شوند.
