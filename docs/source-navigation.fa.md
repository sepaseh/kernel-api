# مسیر‌یابی کد API

[English](source-navigation.md) · [فارسی](source-navigation.fa.md)

از [AGENTS.md](../AGENTS.md) شروع کنید و کار مرتبط را در
[نقشهٔ کارها](../.agents/navigation.json) انتخاب کنید. قرارداد، سرویس، آداپتور،
مسیر HTTP و آزمون‌های صاحب رفتار را با هم بخوانید؛ تطبیق یک نوع به‌تنهایی
رفتار کامل درخواست را اثبات نمی‌کند.

API مالک زمان اجرا و داده‌های خود است و برنامه‌های دیگر از طریق HTTP و مخزن‌های
مستقل به آن متصل می‌شوند. برای احراز هویت و نشست، [آداپتورها](auth-adapters.fa.md)
و [فهرست امنیت](security/authentication-review.fa.md) را ببینید. برای ذخیره‌سازی
و حذف، [ذخیره‌سازی](object-storage.fa.md)، [محدودیت‌های پایگاه داده](database-schema.fa.md)
و [انتقال HTTP](http-transport.fa.md) را بخوانید. برای استقرار و بازیابی از
[استقرار](deployment.fa.md) و [پشتیبان و بازیابی](backup-restore.fa.md) شروع کنید.
برای چرخهٔ آزمون استقرار بومی، کد بسته‌سازی و پاک‌سازی و آزمون‌های مصنوعی خطا را
در کار استقرار بررسی کنید. آزمون‌های پاک‌سازی fixture نیز مالکیت و خطاهای منابع
موقت پایگاه داده را پوشش می‌دهند.

برای تحویل قرارداد API یک صفحه، از [راهنمای مجموعه](collection-guide.fa.md#client-screen-contract-handoff)،
[آزمون قرارداد](contract-testing.fa.md) و [اعتبارسنجی ورودی](input-validation.fa.md) شروع کنید.
برای دنبال‌کردن جریان اجرا از [توالی درخواست‌ها](sequences.fa.md) و
[ثبت رویداد](backend-logging.fa.md) استفاده کنید؛ [فهرست تصمیم‌ها](adr/README.fa.md)
انتخاب‌های معماری را ثبت می‌کند.

برای بررسی‌های اجرایی از [اعتبارسنجی](validation.fa.md) استفاده کنید. فایل محیط
واقعی، دادهٔ موجود یا سرویس تولید را به‌عنوان دادهٔ آزمون محلی به کار نبرید.

سورس اجرایی در src/ است. قرارداد خالص HTTP در ماژول مالک قابلیت زیر src/contracts
قرار دارد و مستقیماً import می‌شود. contracts/locales.ts تنها مرجع خالص مشخصات زبان
برای تنظیمات و نوع کد کاتالوگ است. واژگان نوعی پیام در
src/application/localization.ts و کاتالوگ اجرایی در src/infrastructure/localization/catalogs
قرار دارند. Hono، DB، auth و storage فقط متعلق به API هستند؛ فرانت‌اندهای مستقل از
HTTP استفاده می‌کنند و به سورس این مخزن وابسته نیستند. Bruno، DTO و آزمون HTTP شاهد رفتارند.
